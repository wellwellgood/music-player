# NOCTURNE Music Player

Three.js 비주얼과 YouTube 검색을 결합한 브라우저용 음악 플레이어입니다. 별도 빌드 단계 없이 정적 파일로 실행할 수 있습니다.

## 기능

- **내 음악**: MP3, WAV, AAC, OGG 등 브라우저가 지원하는 오디오 파일을 추가해 재생합니다.
- **브라우저에 보관**: 가져온 오디오 파일은 IndexedDB에, 플레이리스트와 화면 설정은 브라우저 저장소에 저장됩니다. 같은 브라우저에서 다시 열면 라이브러리를 복원합니다.
- **YouTube 검색**: YouTube Data API로 검색하고, YouTube 플레이어에서 선택한 영상을 재생합니다.
- **내 플레이리스트**: 내 음악 또는 YouTube 검색 결과의 `+` 버튼으로 곡을 추가하고, 플레이리스트 탭에서 확인합니다.
- **재생 조작**: 이전 곡, 다음 곡, 자동 다음 곡, 셔플, 반복, 탐색, 볼륨 조절을 지원합니다.
- **가운데 화면 너비 조절**: 캐러셀 오른쪽 손잡이를 드래그하거나 키보드의 `←` / `→` 키로 폭을 조절합니다. 두 번 클릭하면 기본 너비로 돌아갑니다.
- **Three.js 시각 효과**: 오디오 재생에 반응하는 배경 효과를 표시합니다.

> 저장 데이터는 현재 브라우저에만 있습니다. 다른 기기나 브라우저와 동기화하려면 별도의 서버와 계정 기능이 필요합니다. YouTube 곡은 오디오 파일로 다운로드하지 않고 YouTube 임베디드 플레이어로 재생합니다.

## 실행하기

프로젝트 폴더에서 정적 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:8000/
```

Netlify에 배포할 때는 저장소 연결 또는 폴더 업로드 방식으로 이 폴더를 배포하고, 빌드 명령은 비워 두며 게시 디렉터리는 프로젝트 루트로 설정합니다. `index.html`이 기본 진입 파일입니다.

## YouTube 검색 설정

1. Google Cloud 프로젝트에서 **YouTube Data API v3**를 사용 설정합니다.
2. API 키를 만들고, 키 제한에서 YouTube Data API v3만 허용합니다.
3. `youtube API.js`의 `YOUTUBE_API_KEY` 값에 키를 설정합니다.
4. 개발 중에는 로컬 서버 주소를, 배포 후에는 사이트 도메인을 HTTP 리퍼러 허용 목록에 추가합니다.

API 키가 프런트엔드 파일에 들어가므로 브라우저에서 누구나 볼 수 있습니다. 공개 저장소에 키를 올리지 말고, 키 제한을 설정하세요. 키를 이미 공개 저장소에 올렸다면 Google Cloud에서 해당 키를 교체한 뒤 새 키에 제한을 설정합니다.

## 파일 안내
